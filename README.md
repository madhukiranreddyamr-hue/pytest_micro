# Pytest Micro Service Project

## Description
This project is built using Python and Pytest for unit testing. It includes different microservices like student service, marks service, and result service.

## Features
- Student Management
- Marks Calculation
- Result Processing
- Unit Testing using Pytest

## Technologies Used
- Python
- Pytest
- SQLAlchemy (if used)

## Project Structure
- student_service/
- marks_service/
- result_service/

## How to Run
1. Install requirements:
   pip install -r requirements.txt

2. Run tests:
   pytest
